# Проверка готового jar в лаунчере (1.7.3, блок C)

Проверяет владелец. Цель: мод работает так, как его получат игроки, а не только из среды разработки.
Результаты (что не так, где, как повторить) — в `docs/STATUS.md`, раздел «Находки 1.7.3», или просто сообщением в чат.

## Что понадобится

| Файл | Где взять |
|---|---|
| `projectrebirth-1.7.3-dev.jar` | `build\libs\` в папке проекта (собирается `.\gradlew build`) |
| GeckoLib **4.9.3** для NeoForge 1.21.1 (`geckolib-neoforge-1.21.1-4.9.3.jar`) | Modrinth, страница GeckoLib, вкладка Versions, фильтр NeoForge 1.21.1 |
| JEI **19.x** для NeoForge 1.21.1 (необязательно) | Modrinth или CurseForge, страница JEI, фильтр NeoForge 1.21.1 |

Мод требует GeckoLib от 4.9.3 и ниже 5, NeoForge от 21.1.265, JEI (если есть) версии 19.

## Prism Launcher: установка

1. Установить Prism Launcher с prismlauncher.org и войти в аккаунт Microsoft.
2. **Добавить экземпляр** → Minecraft **1.21.1** → загрузчик модов **NeoForge**, версия **21.1.265** (или новее из 21.1.x) → OK.
3. Правой кнопкой по экземпляру → **Изменить** → **Моды** → **Добавить файл** → выбрать jar мода, GeckoLib и JEI.
   (Можно и кнопкой «Скачать моды»: найти GeckoLib и JEI в каталоге Modrinth внутри лаунчера.)
4. Там же, раздел **Настройки** → Java: Prism сам предложит Java 21; память — 4 ГБ (`Максимум` 4096 МБ).
5. **Запустить.**

## Чек-лист

Отметь каждый пункт ✓ или опиши, что не так.

| № | Что сделать | Что должно быть |
|---|---|---|
| 1 | Запуск игры | Игра доходит до главного меню без окна ошибки; в лаунчере нет красных строк с `projectrebirth` |
| 2 | Главное меню → **Моды** → Project: Rebirth | Значок мода (синяя нейроматрица), версия 1.7.3-dev, описание, ссылка на GitHub открывается |
| 3 | Создать мир (выживание) | Мир создаётся, вход без вылета; в первый раз выдаётся Кодекс |
| 4 | Открыть **Кодекс** (ПКМ книгой) | Окно с картой записей, вкладки слева, записи открываются, русский текст помещается |
| 5 | Перейти в творческий режим, открыть вкладки мода в творческом инвентаре | Все вкладки мода на месте, у предметов есть значки (нет фиолетово-чёрных квадратов) |
| 6 | **HUD:** стоять под открытым небом | Слева вверху строки дозы, токсинов, температуры, фильтра и воздуха |
| 7 | **Тело:** поставить капсулу переноса и тело (например, улучшенное роботизированное), лечь в капсулу | Перенос в тело, вид от первого и третьего лица (F5) нормальный, HUD тела (заряд, нагрев, износ), возврат клавишей из подсказки |
| 8 | **Броня:** поставить боевую силовую броню, ПКМ | Раскрытие корпуса, вход, шкалы брони в HUD, выход Shift; вид от первого лица |
| 9 | **Станция:** поставить цех электроники, ПКМ | Окно станции, список рецептов; с JEI — кнопки рецептов станции в JEI |
| 10 | **Машина гарнизона:** поставить малого робота из предмета, затем **пульт**, ПКМ по пульту | Робот стоит и двигается, пульт открывается, робота можно привязать и отдать приказ |
| 11 | **Катастрофа:** команда `/rebirth environment event acid_rain` (нужны права оператора / читы в мире) | Кислотный дождь, частицы, предупреждение и рост токсинов в HUD; `/rebirth environment clear` прекращает |
| 12 | **Звук:** включить громкость, походить в теле и броне, поработать станцией | Звуки мода слышны, субтитры (если включены) по-русски |
| 13 | **Выход и повторный вход:** выйти в меню, зайти в мир снова | Тело, броня, робот, станция и предметы на месте, ничего не задвоилось |
| 14 | Настройки → **Язык** → English, открыть Кодекс и окно станции | Английский текст на месте, без ключей вида `item.projectrebirth...` |
| 15 | Без JEI: убрать JEI из модов экземпляра, запустить | Игра и мир запускаются, станции работают |

Если игра вылетела: в Prism правой кнопкой по экземпляру → **Папка** → `crash-reports` (отчёт о вылете) и `logs\latest.log`. Пришли файл или его начало.
