## Полезные команды

| Команда | Что делает |
|---|---|
| `.\gradlew build` | собирает `build/libs/projectrebirth-<mod_version>.jar` (dev-сборка перезаписывает jar своей версии) |
| `.\gradlew build -x test` | то же без JUnit (игровые автотесты в `build` и так не входят) |
| `.\gradlew runClient` / `runClient2` | тестовый клиент: игрок Dev (`run/`) / Observer (`run-client2/`) |
| `... -PquickPlayServer=localhost` | добавка к клиенту: сразу зайти на запущенный тестовый сервер |
| `.\gradlew runServer` | тестовый выделенный сервер (папка `run/`, мир `run/world`) |
| `.\gradlew runGameTestServer` | все игровые автотесты, сервер сам выключается |
| `... -PgameTests=<группы через запятую>` | только эти группы: `projectrebirth` (основная), `projectrebirth_atmosphere`, `projectrebirth_shelter`, `projectrebirth_codex`, `projectrebirth_power`, `projectrebirth_armor`, `projectrebirth_scouting`, `projectrebirth_garrison` |

- Автотесты нельзя запускать, пока тестовый сервер держит `run/`.
- `gradle clean` не запускать: он удаляет `build/`, где лежат выпущенные jar.

Команды в игре (оператор): `/rebirth status|return|transfer` — перенос; `/rebirth environment …` — среда и катастрофы; `/faction …` — администрирование фракций.

## Известные ограничения

- В искусственном теле руки не принимают позы лука, арбалета и щита.
- Сразу после переноса корпус робота может быть повёрнут не туда, пока игрок не сдвинется.
- Над роботом видно имя игрока.
- Резервным может стать только тело в загруженной области мира.
- Рецепты станций не видны в книге рецептов (видны в окне станции и в JEI).
- keepInventory не действует на вещи робота: при уничтожении тела они всегда выпадают.
- Задержка между переносами не сохраняется при перезапуске сервера.
- Броня: пока сидишь в броне, полоса сытости скрыта; падение с большой высоты отключает броню; время удержания люка не сохраняется при выходе.
- Мех широкий (2,2 блока): не проходит в узкие двери, ходит по открытой местности или перелетает на джетпаке.
- Машины находят посты и зарядные платформы только в загруженных чанках (до 256 блоков); «Обход» выбирает места только в загруженных чанках.
- Полёт меха не сохраняется: после перезагрузки мех стоит на земле.
