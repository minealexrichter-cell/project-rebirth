## Полезные команды

| Команда | Что делает |
|---|---|
| `.\gradlew build` | собирает `build/libs/projectrebirth-<mod_version>.jar` (dev-сборка перезаписывает jar своей версии) |
| `.\gradlew build -x test` | то же без JUnit (игровые автотесты в `build` и так не входят) |
| `.\gradlew runClient` / `runClient2` | тестовый клиент: игрок Dev (`run/`) / Observer (`run-client2/`) |
| `... -PquickPlayServer=localhost` | добавка к клиенту: сразу зайти на запущенный тестовый сервер |
| `.\gradlew runServer` | тестовый выделенный сервер (папка `run/`, мир `run/world`) |
| `.\gradlew runGameTestServer` | все игровые автотесты, сервер сам выключается |
| `... -PgameTests=<группы через запятую>` | только эти группы: `projectrebirth` (основная), `projectrebirth_atmosphere`, `projectrebirth_shelter`, `projectrebirth_codex`, `projectrebirth_power`, `projectrebirth_armor`, `projectrebirth_scouting`, `projectrebirth_garrison` |

- Автотесты нельзя запускать, пока тестовый сервер держит `run/`.
- `gradle clean` не запускать: он удаляет `build/`, где лежат выпущенные jar.

Команды в игре (оператор): `/rebirth status|return|transfer` — перенос; `/rebirth environment …` — среда и катастрофы; `/faction …` — администрирование фракций.

Только в среде разработки (в jar нет): `/rbdev faction create|core|ally|allyaccept|unally|war|warnow|peace …` (от имени игрока: `execute as <игрок> run rbdev …`), `/rbdev machine <предмет> <x y z> <поворот>` — поставить машину как игрок, `/rbdev order <пульт> <приказ> [точка]`, `/rbdev intruders <пульт> true|false`, `/rbdev workshop <угол> <рецепт>` — цех тел со сборкой. 1.8: `/rbdev use <x y z>` — открыть окно блока как ПКМ; `/rbdev ui bench <x y z>` — ряд всех блоков с окнами; клиентские `/rbdev ui check [языки] [масштабы]` (проверка вёрстки, отчёт и снимки в `run/ui_check/`) и `/rbdev ui widgets [0|1]` (витрина виджетов); файлы-запросы `run/ui_cmd.txt` (команда) и `run/ui_shot.txt` (снимок кадра).

## Известные ограничения

- В искусственном теле руки не принимают позы лука, арбалета и щита.
- Сразу после переноса корпус робота может быть повёрнут не туда, пока игрок не сдвинется.
- Над роботом видно имя игрока.
- Резервным может стать только тело в загруженной области мира.
- Рецепты станций не видны в книге рецептов (видны в окне станции и в JEI).
- keepInventory не действует на вещи робота: при уничтожении тела они всегда выпадают.
- Задержка между переносами не сохраняется при перезапуске сервера.
- Броня: пока сидишь в броне, полоса сытости скрыта; падение с большой высоты отключает броню; время удержания люка не сохраняется при выходе.
- Мех широкий (2,2 блока): не проходит в узкие двери, ходит по открытой местности или перелетает на джетпаке.
- Машины находят посты и зарядные платформы только в загруженных чанках (до 256 блоков); «Обход» выбирает места только в загруженных чанках.
- Полёт меха не сохраняется: после перезагрузки мех стоит на земле.

## Структура кода

Пакеты `com.projectrebirth` (главные классы):

- `ProjectRebirth` — точка входа, регистрации; `config/RebirthConfig` — серверный конфиг баланса.
- `core` — `ModSounds`, `ModCreativeTabs`, `Parked` (неподвижные пустые тела и броня).
- `bodies` — перенос и тела:
  - `TransferService` (перенос, возврат, гибель тела), `ShellRegistry`, `PossessionState`, `BodyAttachments`;
  - `ArtificialBodyEntity`, `HumanShellEntity`, `TransferCapsuleBlock`, `BodyClass`, `BodyRules`, `BodyInventory`, `BodyGadgets`, `Jetpack`;
  - `bodies/power` — заряд, нагрев, износ тел, зарядная платформа.
- `powerarmor` — `PowerArmorEntity` (две шкалы, управление, люк, ремонт), `ArmorVariant`, `ArmorAbility`, `WorkerMining`, `ArmorMountingMenu`.
- `weapons` — `Weapons`, `WeaponDefinition`, `WeaponItem`, `WeaponState`, пакеты выстрела.
- `upgrades` — `Upgrades`, `UpgradeDefinition`, `InstalledUpgrades`, `UpgradeLayout`, `UpgradeHost`.
- `technology` — руды и детали, станции (`Station`, `StationBlockEntity`, `FabricationRecipe`), станция обслуживания (`Maintenance`), станция модификации тел; `technology/energy` — буфер, генераторы (сгорания, солнечный, РИТЭГ), аккумуляторы, кабель и его сеть, жизнеобеспечение.
- `factions` — `Faction`, `FactionData`, `FactionService` (правила, дружественный огонь, войны), `FactionRole`, ядро фракции, синхронизация, команды.
- `environment` — среда (`Environment`, `Exposure`, `Hazard`, `Protection`, `Temperature`), катастрофы (`Catastrophes`, `Emi`), заражённые зоны и источники радиации, человек (`HumanBody`, симптомы, лекарства), защитное снаряжение, команды.
- `shelter` — герметичные помещения (`RoomScan`, `Sealing`), фильтрация воздуха, шлюзы, дезактивация, панель убежища, тревоги.
- `water` — загрязнение воды, водоочиститель, бутылки. `weather` — метеостанция и прогноз. `monitoring` — станция экологического мониторинга, карта заражения. `scouting` — полевой анализатор, сенсоры разведки.
- `structures` — руины и большие структуры (jigsaw, размещение, выключатели), декоративные блоки, тревожная лампа, турель руин.
- `hostile` — враги:
  - `WalkingGunner` (общая основа), `PatrolRobotEntity`, `MechEntity`, `GuardTurretEntity`;
  - мутанты (`MutantEntity`, пёс, гуль, громила, `MutantSpawner`);
  - `Gunnery` (общая стрельба), `RemainsEntity` (остовы и обломки).
- `multiblock` — `MultiblockSchema` (схема из данных), `AssemblyRecipe`, контроллер, порты, манипуляторы, `MultiblockTracker`.
- `garrison` — машины игрока:
  - `MachineCore` (владелец, две шкалы, износ, остов), `MachineEntity`, `MachineRegistry`, `TargetRules`, `MachineTask`;
  - `GuardMechEntity` (+ `MechJetpack`), `SmallRobotEntity`, `DefenceTurretEntity` с `TurretMount`, `AndroidEntity` с `AndroidWork`;
  - движение: `MachineMover`, `MachineNavigation`, `AreaPatrol`; посты и платформы: `LoadedSites`;
  - пульт: `ConsoleBlockEntity`, `ConsoleLink`, `ConsoleNetwork`, `ConsoleAlarm`; планшет: `TabletItem`, `TabletData`; пост: `ServicePostBlockEntity`, `ServicePostPlateBlock`.
- `codex` — Кодекс перерождения (книга, записи из данных `assets/projectrebirth/codex/`).
- `mixin` — `LivingEntityMixin` (иммунитет машин к зельям), `ItemStackMixin` (бутылки по 16).
- `client` — всё клиентское: рендереры (`client/render`), окна (`client/screen`), библиотека интерфейса стиля A (`client/ui`, 1.8), HUD, Кодекс, гарнизон, мультиблоки, JEI (`client/jei`), эффекты катастроф.
- `gametest` — игровые автотесты по группам (`PlanTests`); площадки `data/projectrebirth*/structure/floor_*.nbt` (3×3 и 5×5 основной группы, 9×9 у групп power, shelter, scouting, garrison).
